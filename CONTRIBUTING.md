# Contributing 🐾

Repup is intentionally playful.

The best contributions are small ideas that make the pet feel more alive.

## Ideas

- new moods
- new ASCII faces
- commit reactions
- GitHub integrations
- animations
- mini-games
- AI personality
- weird easter eggs

## Development

```bash
npm install
npm run dev
```

Keep dependencies minimal where possible.

If a feature can be built without an API, that's usually the better first version.
